## Adding songs

Drop the MP3 in this folder under the file name below, then run `godot --headless --import --path .` (the editor does it on focus). Songs whose file is missing are skipped automatically: no CD drops for them and they are not on the CD player. The list, artists and unlock rules are in `data/songs.json` (`systems/tunes.gd`).
